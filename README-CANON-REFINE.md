# Mundo Biohack — V15.1 Canonical Refine

Esta versión parte del ZIP canónico original `MUNDOBIOHACK-main` y conserva su arquitectura, contenido, identidad e imágenes de Imgur.

## Qué se tocó
- Escala general más contenida en desktop.
- Hero más proporcional, sin ocupar casi todo el viewport.
- Cards y secciones con menos altura y aire muerto.
- Responsive estabilizado para tablet y mobile.
- Navegación y tipografía mobile más compactas.
- Productos, TV, temas, clips y selección editorial conservan la estructura original.
- Se mantienen todos los links e imágenes existentes de Imgur.
- No se eliminó ninguna sección.
- No se reescribió el posicionamiento ni la arquitectura.

## Enfoque
Esta es una base visual de continuidad. A partir de acá conviene iterar sección por sección y bloquear cada sección aprobada antes de pasar a la siguiente.
